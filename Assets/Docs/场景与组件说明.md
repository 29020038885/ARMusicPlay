# 乐器 3D 模型与场景组件说明（更新后）

本文说明当前工程下，**3D 模型上需要哪些组件**，以及**场景里需要新建哪些物体、挂哪些脚本**，才能正常跑通古琴/琵琶的触控与 PC 测试。

协作与二次开发（新增功能/改脚本定位/排错清单）请看：[协作开发指南](./协作开发指南.md)。

---

## 一、3D 模型上需要的组件

### 1. 古琴 / 琵琶根物体（乐器根节点）

| 组件 | 说明 |
|------|------|
| **GuqinController**（古琴）或 **PipaController**（琵琶） | 必须。挂在乐器根节点上，负责弦数组、品位、奏法、拨弦/按品/推拉逻辑。 |
| **Transform** | 默认就有，用于摆放乐器位置。 |

- 不要求在根节点上挂 **Collider**，碰撞在「弦」和「品位」上。

---

### 2. 每根「弦」对应的物体（必须）

每一根可拨的弦对应一个 **子物体**，该物体上需要：

| 组件 | 是否必须 | 说明 |
|------|----------|------|
| **InstrumentString** | ✅ 必须 | 弦逻辑：拨弦、按品音高、泛音、推拉、震动反馈。脚本内 `[RequireComponent(typeof(Collider))]` 会要求有碰撞体。 |
| **Collider**（如 BoxCollider） | ✅ 必须 | 用于射线检测「点到的是哪根弦」。建议用 BoxCollider，大小包住该弦的拨弦区域。 |
| **AudioSource** | 建议 | 若不挂，InstrumentString 会在运行时 `AddComponent<AudioSource>`。提前挂好可避免警告。 |
| **Renderer**（如 MeshRenderer） | 二选一 | 用于默认的「弦视觉 + 颜色反馈」。若用下面「单独视觉弦」则这里可做碰撞用、可设为透明。 |

可选（同一物体上）：

- **visualStringObject**（在 InstrumentString 里填）：指向**另一个**只负责显示的弦模型 Transform，则震动、颜色反馈会作用在那个物体上，碰撞弦可做成透明。

总结：**每根弦 = 一个带 InstrumentString + Collider 的子物体**（+ 可选 AudioSource / Renderer 或 visualStringObject）。

---

### 3. 品位（按品/泛音）碰撞体——两种做法

#### 方式 A：代码自动生成（推荐）

- 在 **GuqinController** / **PipaController** 上勾选 **Create Fret Colliders Per String**（或类似选项），不手动拖 **Fret Colliders**。
- 运行后会在乐器下自动生成：
  - 根物体：`FretCollidersPerString`
  - 下面每根弦一个子物体：`String_1_Frets`, `String_2_Frets`, ...
  - 每个品位一个子物体：`String_X_Fret_Y`，上面自动带 **BoxCollider** + **FretInfo**（脚本会设置 `stringIndex`、`fretIndex`）。
- **你不需要在 3D 模型上新建任何品位物体**，只需保证弦的 `strings` 数组在 Controller 里正确引用。

#### 方式 B：手动摆品位碰撞体

- 为每根弦、每个品位做一个**单独物体**，放在对应弦附近。
- 每个物体上需要：
  - **Collider**（如 BoxCollider），用于射线检测；
  - **FretInfo**：`stringIndex` = 弦索引（0 起），`fretIndex` = 品索引（0 起）；若该区域表示「空弦」可勾选 `treatAsOpenString`。
- 在 Controller 里取消勾选「自动创建品位」，并把这一组碰撞体赋给 **Fret Colliders**（或按你代码里的数组结构赋值）。

无论 A 还是 B，**品位热区建议按模型真实品位置摆放**；相邻品可略微重叠，避免滑音时断开。

## 二、场景里需要的新建物体与脚本（与 3D 模型无关）

这些是**场景级**的，不是挂在乐器 3D 模型上的。

### 1. 输入管理器（必须）

| 物体 | 脚本 | 说明 |
|------|------|------|
| 新建空物体，例如命名为 **InputManager** | **InstrumentInputManager** | 负责鼠标/触控、射线检测、调用古琴/琵琶的拨弦与按品。 |

Inspector 中建议设置：

- **Input Camera**：用于射线检测的摄像机（通常 Main Camera）。
- **Guqin Controller** / **Pipa Controller**：拖场景中的古琴、琵琶根物体（带 GuqinController/PipaController 的）。
- **Auto Detect Platform**：勾选后编辑器用鼠标、真机用触控。
- 其他如射线距离、扫弦阈值、推拉灵敏度等按需调整。

### 2. 摄像机

- 场景中需要有 **Camera**（如 Main Camera）。
- InstrumentInputManager 的 **Input Camera** 指向它；不指定时会用 `Camera.main`。

### 3. 音频管理器（若用程序化/统一音频）

| 物体 | 脚本 | 说明 |
|------|------|------|
| 新建空物体，例如 **AudioManager** | **InstrumentAudioManager** | 管理音频加载/程序化生成等；InstrumentString 会通过 FindObjectOfType 查找。 |

若你完全用弦自己的 `fretSounds` / `openStringSound`，不依赖统一管理，可以不建；否则建议建一个避免空引用。

### 4. EventSystem（UI 不挡射线时可选）

- 若有 **Canvas + UI**，且需要「点击 UI 不触发拨弦」，场景里要有 **EventSystem**（Unity 新建 UI 时通常会自带）。
- InstrumentInputManager 里用 `EventSystem.current.IsPointerOverGameObject(...)` 判断是否点在 UI 上。

### 5. 可选：一键场景配置

| 物体 | 脚本 | 说明 |
|------|------|------|
| 任意物体（如空物体 **SceneSetup**） | **InstrumentSceneSetup** | 可勾选 **Auto Setup On Start**，运行时自动创建 InputManager、AudioManager、并给古琴/琵琶挂 Controller、找弦。适合快速测试。 |

若你**手动**摆好古琴/琵琶和 InputManager，可以不挂 InstrumentSceneSetup。

## 三、层级结构小结

```
场景
├── Main Camera（或你的射线用摄像机）
├── EventSystem（若有 UI）
├── InputManager（空物体 + InstrumentInputManager）
├── AudioManager（可选，空物体 + InstrumentAudioManager）
├── Guqin（古琴 3D 模型根）
│   ├── GuqinController（组件）
│   ├── 弦1（子物体：InstrumentString + Collider + 可选 AudioSource/Renderer）
│   ├── 弦2
│   ├── …
│   └── FretCollidersPerString（若用自动生成，运行时出现）
│       ├── String_1_Frets → String_1_Fret_1（BoxCollider + FretInfo）, …
│       └── …
└── Pipa（琵琶 3D 模型根）
    ├── PipaController（组件）
    ├── 弦1（InstrumentString + Collider + …）
    ├── …
    └── FretCollidersPerString（若用自动生成，运行时出现）
```

## 四、新建物体与挂载脚本速查

| 要新建的物体 | 挂载的脚本 | 必须？ |
|--------------|------------|--------|
| InputManager（空物体） | InstrumentInputManager | ✅ 必须 |
| AudioManager（空物体） | InstrumentAudioManager | 建议（若用统一音频） |
| SceneSetup（任意） | InstrumentSceneSetup | 可选（自动配置用） |
| 每根弦子物体 | InstrumentString + Collider | ✅ 必须（每根弦一个） |
| 品位碰撞体（若手动画） | FretInfo + Collider | 仅在不使用「自动创建品位」时需要 |

**3D 模型上**：乐器根挂 **GuqinController** 或 **PipaController**；每根弦子物体挂 **InstrumentString** + **Collider**（+ 可选 AudioSource/Renderer）。品位推荐用代码自动生成（带 **FretInfo**），或手动画格子并挂 **FretInfo**。  
**场景里**：至少新建 **InputManager** 并挂 **InstrumentInputManager**，指定摄像机与两个乐器控制器；其余按上表可选添加。
